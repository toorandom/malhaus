REST API & MCP

Submit files and URLs for automated malware analysis. Results appear in the web UI alongside browser submissions. To obtain an API key, contact the administrator of this malhaus instance — keys are issued via the admin dashboard and may carry a rate limit and expiry date.

Authentication

Pass your API key as a bearer token in the Authorization header on every request:

Authorization: Bearer mh_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Keys are issued by the admin and may carry a per-hour rate limit and an optional expiry date. Revoked or expired keys receive a 401 Unauthorized response.

Python examples

Copy the script below and run it directly. Requires the requests library — pip install requests.

#!/usr/bin/env python3
"""
malhaus-submit — submit files or URLs to a malhaus instance via the REST API.

Usage
-----
  # Analyze a file
  python malhaus_submit.py --file suspicious.exe

  # Analyze with Ghidra decompilation (deeper, slower)
  python malhaus_submit.py --file binary.exe --ghidra

  # Submit a URL
  python malhaus_submit.py --url https://example.com/payload.ps1

  # Submit an encrypted archive (ZIP / 7z / RAR)
  python malhaus_submit.py --file malware.zip --password infected

  # Override server / key for this run
  python malhaus_submit.py --file sample.exe --server https://malhaus.example.com --key mh_xxx

Environment variables (used when --server / --key are not passed):
  MALHAUS_URL   base URL of the malhaus instance
  MALHAUS_KEY   your API key  (mh_…)
"""

import argparse
import os
import sys
import time
import requests

# ── Default configuration ──────────────────────────────────────────────────────
DEFAULT_SERVER = os.environ.get("MALHAUS_URL", "https://your-malhaus-instance.example.com")
DEFAULT_KEY    = os.environ.get("MALHAUS_KEY",  "mh_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx")
POLL_INTERVAL  = 5   # seconds between status checks


# ── Helpers ────────────────────────────────────────────────────────────────────
def submit(server: str, key: str, args: argparse.Namespace) -> str:
    """Submit a file or URL and return the job_id."""
    headers = {"Authorization": f"Bearer {key}"}
    endpoint = f"{server}/api/v1/analyze"

    if args.file:
        path = args.file
        extra = {}
        if args.password:
            extra["archive_password"] = args.password   # encrypted ZIP / 7z / RAR
        if args.ghidra:
            extra["use_ghidra"] = "1"                   # Ghidra decompilation (takes longer)

        with open(path, "rb") as fh:
            resp = requests.post(
                endpoint,
                headers=headers,
                files={"file": (os.path.basename(path), fh, "application/octet-stream")},
                data=extra,
                timeout=120,
            )
    elif args.url:
        extra = {}
        if args.ghidra:
            extra["use_ghidra"] = "1"
        resp = requests.post(
            endpoint,
            headers=headers,
            data={"url": args.url, **extra},
            timeout=120,
        )
    else:
        print("error: provide --file or --url", file=sys.stderr)
        sys.exit(1)

    if resp.status_code == 401:
        print("error: API key rejected (401 Unauthorized)", file=sys.stderr)
        sys.exit(1)
    if resp.status_code == 429:
        print("error: rate limit exceeded (429). Try again later.", file=sys.stderr)
        sys.exit(1)
    resp.raise_for_status()
    return resp.json()["job_id"]


def poll(server: str, key: str, job_id: str) -> dict:
    """Poll until the job is done or failed. Returns the result dict."""
    headers = {"Authorization": f"Bearer {key}"}
    url = f"{server}/api/v1/jobs/{job_id}"
    while True:
        resp = requests.get(url, headers=headers, timeout=30)
        resp.raise_for_status()
        data = resp.json()
        status = data.get("status", "unknown")
        print(f"  [{status}]", flush=True)
        if status in ("done", "failed"):
            return data
        time.sleep(POLL_INTERVAL)


def print_result(data: dict) -> None:
    """Print a human-readable summary of a completed job."""
    if data.get("status") == "failed":
        print("Analysis failed:", data.get("error"))
        return

    verdict    = data.get("verdict", {})
    risk       = verdict.get("risk_level", "unknown")
    confidence = verdict.get("confidence", "?")
    file_type  = verdict.get("file_type", "")
    reasons    = data.get("top_reasons", [])
    tools      = data.get("tools_used", [])
    sha256     = data.get("sha256", "")
    h_score    = data.get("heuristic_score", "?")
    s_score    = data.get("strings_score", "?")
    report_url = data.get("report_url", "")

    print(f"\n{'─'*60}")
    print(f"  risk           : {risk.upper()}")
    print(f"  confidence     : {confidence}%")
    print(f"  file type      : {file_type}")
    print(f"  heuristic score: {h_score}/100")
    print(f"  strings score  : {s_score}/100")
    if sha256:
        print(f"  sha256         : {sha256}")
    if report_url:
        print(f"  report         : {report_url}")
    print(f"\n  Top reasons:")
    for reason in reasons[:5]:
        print(f"    • {reason}")
    if tools:
        print(f"\n  Tools used : {', '.join(tools)}")
    print(f"{'─'*60}\n")


# ── Entry point ────────────────────────────────────────────────────────────────
def main():
    parser = argparse.ArgumentParser(
        prog="malhaus_submit",
        description="Submit a file or URL to malhaus for static malware analysis.",
    )
    src = parser.add_mutually_exclusive_group(required=True)
    src.add_argument("--file",     metavar="PATH", help="Path to the file to analyse")
    src.add_argument("--url",      metavar="URL",  help="URL to download and analyse")
    parser.add_argument("--password", metavar="PW",  default="",
                        help="Password for encrypted ZIP / 7z / RAR archives")
    parser.add_argument("--ghidra", action="store_true",
                        help="Enable Ghidra decompilation (deeper analysis, takes longer)")
    parser.add_argument("--server", metavar="URL",  default=DEFAULT_SERVER,
                        help="malhaus base URL (default: $MALHAUS_URL or hard-coded above)")
    parser.add_argument("--key",    metavar="KEY",  default=DEFAULT_KEY,
                        help="API key (default: $MALHAUS_KEY or hard-coded above)")
    args = parser.parse_args()

    target = args.file or args.url
    print(f"Submitting: {target}")
    job_id = submit(args.server, args.key, args)
    print(f"Job ID: {job_id}")
    print("Polling for results…")
    result = poll(args.server, args.key, job_id)
    print_result(result)


if __name__ == "__main__":
    main()

MCP (Model Context Protocol)

Malhaus exposes an MCP server on port 8001 using the Streamable HTTP transport. Any MCP-compatible AI assistant or agent (Claude Code, Claude Desktop, custom Python agents, etc.) can connect to it and call malware analysis as a native tool — no shell scripts, no manual API polling.

Server setup

The MCP server needs a malhaus API key to submit jobs internally. Without this key the MCP server starts but all tool calls return an error. 

# 1. Log in to the malhaus admin panel and create an API key
#    Admin → API Keys → Create key  (label it e.g. "mcp-internal")

# 2. Open .env and set MALHAUS_MCP_API_KEY — it is already present as a placeholder:
#
#    MALHAUS_MCP_API_KEY=mh_REPLACE_WITH_YOUR_KEY_FROM_ADMIN_PANEL
#
#    Replace the placeholder with the real key you just generated.
nano ~/malhaus/.env

# 3. Rebuild and restart (required — the key is read at startup)
cd ~/malhaus && docker compose up --build -d

# 4. Verify the MCP server is running (any response = server is up)
curl http://localhost:8001/mcp

The key is only used internally inside the container — the MCP server uses it to submit jobs to the REST API. It is not a client-facing credential and never leaves the server.

Available tools

ToolArgumentsDescription
analyze_file file_b64, filename Analyze a file from base64-encoded content. Returns verdict, confidence, heuristic score, top reasons, IOCs. Typical duration: 30–120 s.
analyze_url url Download a file from a URL and analyze it.
analyze_sha256 sha256 Retrieve a cached result by SHA-256 hash. Instant if previously analyzed.

Port layout

Port 80 / 443 — nginx → web UI + REST API (https://your-server/)
Port 8000 — gunicorn (internal only, not exposed outside Docker)
Port 8001 — MCP server (http://your-server:8001/mcp) — this is what MCP clients connect to

The MCP server runs as a second process inside the container, started alongside the web app. MCP clients connect directly to port 8001 — they do not go through nginx. Make sure port 8001 is open in your firewall for the machines that need MCP access. Clients do not need anything installed locally — just the URL.

How local file analysis works

The MCP server runs inside Docker on your server — it has no access to files on your machine. When you ask the AI to analyze a local file (e.g. C:\Users\analyst\Downloads\invoice.exe or /home/analyst/samples/dropper.elf), the client (the AI agent) reads the file, encodes it as base64, and passes the bytes to analyze_file. The server receives bytes, not a path — it never touches your filesystem.

Local file — Linux: /home/analyst/samples/dropper.exe
Local file — Windows: C:\Users\analyst\Downloads\invoice.exe
  → agent reads file bytes from that path on the client machine
  → agent base64-encodes the bytes
  → agent calls analyze_file(file_b64="TVqQAAMA...", filename="dropper.exe")
  → server decodes → runs full analysis → returns verdict

Remote URL: https://cdn.example.com/updater.ps1
  → agent calls analyze_url(url="https://cdn.example.com/updater.ps1")
  → server downloads the file from that URL → runs analysis → returns verdict

Cached by hash: 4d4a8de9f4c07e6b8b23...
  → agent calls analyze_sha256(sha256="4d4a8de9f4...")
  → returns instantly if previously analyzed, otherwise asks you to submit the file

Client: Python (direct MCP SDK)

Install: pip install mcp — works on Linux, macOS, and Windows.
The script reads files on the client machine before sending — the server never touches your filesystem. 

#!/usr/bin/env python3
"""
malhaus-mcp-client — analyze files and URLs via the malhaus MCP server.

Usage examples:
  # Analyze a local file (Linux / macOS)
  python malhaus_mcp.py file /home/analyst/samples/dropper.exe
  python malhaus_mcp.py file /mnt/evidence/case-2024/payload.ps1

  # Analyze a local file (Windows — use quotes if path has spaces)
  python malhaus_mcp.py file "C:\\Users\\analyst\\Downloads\\invoice.exe"
  python malhaus_mcp.py file "D:\\malware-samples\\ransomware_sample.bin"

  # Analyze a remote URL (server downloads it)
  python malhaus_mcp.py url https://cdn.example.com/updater.ps1
  python malhaus_mcp.py url http://192.168.1.100/share/suspicious.exe

  # Check if a SHA-256 was already analyzed (instant cache lookup)
  python malhaus_mcp.py sha256 4d4a8de9f4c07e6b8b23c2a1e0f6d3a9b5e2c8d1f7a05031e6b8b2a9c4f70d1e

pip install mcp
"""
import asyncio
import base64
import os
import sys
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

# Set MALHAUS_MCP_URL or edit the default below
SERVER_URL = os.environ.get("MALHAUS_MCP_URL", "http://your-server:8001/mcp")


async def _call(tool: str, args: dict) -> str:
    async with streamablehttp_client(SERVER_URL) as (read, write, _):
        async with ClientSession(read, write) as session:
            await session.initialize()
            result = await session.call_tool(tool, args)
            return result.content[0].text


async def analyze_local_file(path: str) -> str:
    """
    Read a file from THIS machine, base64-encode it, and submit for analysis.
    The file is read here (client side) — the server never accesses your filesystem.

    Linux:   path = "/home/analyst/samples/dropper.exe"
    Windows: path = "C:\\Users\\analyst\\Downloads\\invoice.exe"
    """
    with open(path, "rb") as fh:
        file_b64 = base64.b64encode(fh.read()).decode()
    filename = os.path.basename(path)
    print(f"[*] Submitting local file: {path}  ({filename})", flush=True)
    return await _call("analyze_file", {"file_b64": file_b64, "filename": filename})


async def analyze_remote_url(url: str) -> str:
    """
    Tell malhaus to download the file at the given URL and analyze it.
    The server fetches the file — the client does not.

    Example: url = "https://cdn.example.com/updater.ps1"
    """
    print(f"[*] Submitting URL: {url}", flush=True)
    return await _call("analyze_url", {"url": url})


async def check_cached_sha256(sha256: str) -> str:
    """
    Retrieve a cached result by SHA-256. Returns instantly if analyzed before.

    Example: sha256 = "4d4a8de9f4c07e6b8b23c2a1e0f6d3a9b5e2c8d1f7a0..."
    """
    print(f"[*] Checking cache for SHA-256: {sha256}", flush=True)
    return await _call("analyze_sha256", {"sha256": sha256})


if __name__ == "__main__":
    if len(sys.argv) != 3:
        print("Usage:")
        print("  malhaus_mcp.py file   /path/to/local/file.exe")
        print('  malhaus_mcp.py file   "C:\\\\Users\\\\analyst\\\\Downloads\\\\invoice.exe"')
        print("  malhaus_mcp.py url    https://example.com/remote-file.ps1")
        print("  malhaus_mcp.py sha256 4d4a8de9f4c07e6b...")
        sys.exit(1)

    mode, value = sys.argv[1], sys.argv[2]
    if mode == "file":
        print(asyncio.run(analyze_local_file(value)))
    elif mode == "url":
        print(asyncio.run(analyze_remote_url(value)))
    elif mode == "sha256":
        print(asyncio.run(check_cached_sha256(value)))
    else:
        print(f"Unknown mode '{mode}'. Use: file, url, or sha256")
        sys.exit(1)

Client: Databricks (Mosaic AI / notebook)

Analyze files stored in DBFS, Unity Catalog Volumes, or cloud storage from a Databricks notebook or AI Agent. Install in your cluster: %pip install mcp 

import asyncio, base64, os
from mcp import ClientSession
from mcp.client.streamable_http import streamablehttp_client

MALHAUS_MCP_URL = "http://your-server:8001/mcp"   # reachable from Databricks cluster


async def analyze_dbfs_file(dbfs_path: str) -> str:
    """
    Analyze a file stored in DBFS or a Unity Catalog Volume.

    Examples:
      dbfs_path = "/dbfs/FileStore/malware-samples/dropper.exe"
      dbfs_path = "/Volumes/main/security/incoming/suspicious.ps1"
      dbfs_path = "/Volumes/main/security/incoming/ransomware_sample.bin"
    """
    with open(dbfs_path, "rb") as fh:
        file_b64 = base64.b64encode(fh.read()).decode()
    filename = os.path.basename(dbfs_path)
    async with streamablehttp_client(MALHAUS_MCP_URL) as (r, w, _):
        async with ClientSession(r, w) as s:
            await s.initialize()
            result = await s.call_tool(
                "analyze_file", {"file_b64": file_b64, "filename": filename}
            )
            return result.content[0].text


async def analyze_cloud_url(url: str) -> str:
    """
    Analyze a file via a presigned cloud storage URL (S3, Azure Blob, GCS).
    The malhaus server downloads the file directly.

    Examples:
      url = "https://myaccount.blob.core.windows.net/samples/payload.exe?sv=2023-01-03&..."
      url = "https://s3.amazonaws.com/my-bucket/samples/dropper.exe?X-Amz-Signature=..."
    """
    async with streamablehttp_client(MALHAUS_MCP_URL) as (r, w, _):
        async with ClientSession(r, w) as s:
            await s.initialize()
            result = await s.call_tool("analyze_url", {"url": url})
            return result.content[0].text


# In a Databricks notebook cell:

# Analyze a Unity Catalog Volume file:
result = asyncio.run(analyze_dbfs_file(
    "/Volumes/main/security/incoming/suspicious_dropper.exe"
))
print(result)

# Analyze via presigned Azure Blob URL:
result = asyncio.run(analyze_cloud_url(
    "https://myaccount.blob.core.windows.net/samples/invoice.doc?sv=2023-01-03&..."
))
print(result)

File size limits

The REST API enforces MALHAUS_MAX_UPLOAD_MB (default: 10 MB). The analyze_file MCP tool sends base64-encoded content, which expands the size by ~33%. A 10 MB file becomes ~13.3 MB of base64 text — this is fine for most malware samples (PE, Office docs, scripts). If your file is larger than the limit, use analyze_url instead: upload the file to any reachable HTTP endpoint (S3, Azure Blob with SAS, Nginx directory listing, etc.) and pass the URL. The server downloads it directly with no base64 overhead.

File ≤ 10 MB → use analyze_file(file_b64=..., filename="sample.exe")
File > 10 MB → upload to S3/Azure Blob/any URL, then use analyze_url(url="https://...")

Server environment variables

  • MALHAUS_MCP_API_KEY Required. A malhaus API key (mh_...) created in the admin panel. Used internally by the MCP server to authenticate with the REST API. Not exposed to MCP clients.
  • MALHAUS_MCP_PORT MCP server listen port. Default: 8001. Change only if 8001 conflicts with something else on the host.
  • MALHAUS_INTERNAL_URL Internal REST API base URL. Default: http://localhost:8000. Only change if the REST API runs on a different host/port.
  • MALHAUS_PUBLIC_URL Override the public base URL used in report links returned by MCP tools (e.g. https://malhaus.example.com). If not set, the URL is automatically derived from the incoming request's Host header — usually no configuration needed.

Endpoints

Method Path Description
POST /api/v1/analyze Submit a file or URL for analysis. Returns {"job_id": "..."} immediately. Body can be multipart/form-data (file upload) or application/x-www-form-urlencoded (URL submission). Optional fields: use_ghidra=1, archive_password.
GET /api/v1/jobs/<job_id> Poll job status. Returns a JSON object with status (pending / running / done / error), and on completion a result dict or error string.

Response fields (status: done)

  • status pending · running · done · failed — current job state. Poll until done or failed.
  • job_id UUID of the analysis job, as returned by POST /api/v1/analyze.
  • verdict.risk_level benign · suspicious · likely_malware — overall verdict from the LLM loop.
  • verdict.confidence Integer 0–100 — how confident the model is in the verdict.
  • verdict.file_type Detected file type string (e.g. pe, elf, pdf).
  • top_reasons List of strings — the most significant evidence items from the analysis.
  • heuristic_score Deterministic score 0–100 computed before the LLM pass (entropy, imports, IOC hits, etc.).
  • strings_score Score 0–100 based on string analysis (suspicious patterns, URLs, registry keys, etc.).
  • strings_summary Short LLM-generated summary of notable strings found in the file.
  • tools_used List of static analysis tools that ran (e.g. objdump, olevba, ghidra).
  • tool_outputs Dict mapping tool name → {stdout, stderr, error} — raw output from each tool.
  • sha256 SHA-256 of the submitted file. Results are cached by hash — resubmitting an identical file returns instantly.
  • report_url Relative URL to the HTML report page for this analysis.
  • report_json_url Relative URL to the full raw JSON report.
  • html_summary Pre-rendered HTML snippet with a human-readable summary — useful for embedding in ticketing systems or chat bots.
